## 2. Feasibility and gaming (D), summary

- **Workload.** 160 rows, four viewports times every state for assertions, live-original target validation to 0 failures, a numeric motion gate, three engines (RSP-06), Lighthouse 3x2 on two sites, a 3-cycle polish loop and 12 gates. This is plausibly two to four long agent sessions of work. The items most likely to be skipped or faked are target validation reaching 0 on a live, changing site; the motion gate (H8); RSP-06 WebKit and Firefox; MOT-01 and MOT-05 traces; TYP-06 and TYP-22 (M11); and the hand-filled rows.
- **Gaming vectors found.** The `substituted` layer (M2), `N/A` on G rows with free text (M10), `unreached[]` (M20), the self-authored lock (M4), smoke fixtures the agent designs itself (M3), subjective smoothness (M17), the localhost performance advantage (M9), and a SHA-256-only asset check (see G5 below).
- **Tightening beyond the table.** Require a single `npm run gates` in `WS/tools` that re-runs every gate from the saved inputs and regenerates `production.md` and the README gate table; gate 9 then diffs README against that output. Require the README to print the raw assertion counts per viewport and layer, so a thin assertion set is visible.

## 3. Missing production topics worth adding (G), all verifiable

- G1. **Audio**: autoplaying sound is off by default, a visible toggle exists only if the original has one, WCAG 1.4.2. Verify with a Playwright check that no `AudioContext` is `running` and no unmuted media is playing before user activation. Class C.
- G2. **Frame-rate independence**: lerps and inertia use elapsed time, not a per-frame constant. Verify by running the scroll trace with rAF throttled to 30 fps (override `requestAnimationFrame` to skip every other frame); end positions and timings must stay within the motion-gate tolerances. Class G for any JS-driven motion. This matters on 120 Hz displays.
- G3. **Autoplay-rejection fallback**: monkeypatch `HTMLMediaElement.prototype.play` to reject (iOS Low Power Mode). The poster stays, there are no console errors, and the layout doesn't change. Class C.
- G4. **One WebGL context, bounded GPU memory**: count `getContext('webgl'/'webgl2')` calls, and log `renderer.info.memory` after 5 scroll passes, which must be stable. Class C.
- G5. **Asset-lifting check beyond SHA-256**: perceptual hash (dHash) of every shipped raster against every evidence image must be at Hamming distance > 10, and no shipped CSS/JS line of more than 60 characters may appear verbatim in the evidence stylesheets. This strengthens P rule 4 and gate 6.
- G6. **Passive listeners**: wheel and touch listeners are registered `{passive:true}` unless they call `preventDefault` (Lighthouse 13 removed this audit). Verify by wrapping `addEventListener` in an init script. Class G.
- G7. **Font licensing detail**: SIL OFL Reserved Font Names versus subsetting (TYP-01 requires subsetting). Record for each font whether it declares an RFN and how subsetting complies. I could not verify the current OFL-FAQ position, so this is listed as a check, not a claim.
