# Checklist row review, 2026-10-05

This companion review records mixed requirements and priority corrections found while assigning tiers. It does not alter stable IDs or replace the checklist. The current canonical working tree contains primary-review edits to SPD-06, EDGE-02, LEG-04, LEG-09, LEG-12, LEG-17 and OPS-02; those rows should be read in their current form.

| Rows | Recommended split or correction |
|---|---|
| SPD-01, SPD-13, SPD-14, SPD-15, SPD-17, SPD-18, SPD-20, OPS-02 | Keep lab thresholds, byte caps, score bars and latency limits as Gold agency budgets. They are not field Core Web Vitals, WCAG conformance or a third-party certification. Preserve truthful measurement and safe loading separately. |
| SPD-06 | Primary reviewer revised the cache rule. Keep privacy-safe cache isolation and correct freshness as Diamond; host-specific ETags, mandatory hashed files, and one cache recipe are not universal requirements. |
| SPD-21, SEO-13, OPS-08 | Schedule field vitals and indexing follow-up after a real deployment and sufficient real traffic. Seven- and thirty-day observations cannot be prelaunch evidence or invented to close a gate. |
| TYP-01, LEG-01 | Separate self-hosting/privacy from WOFF2, Unicode subsetting and font-display implementation choices. Avoid external font disclosure; allow an equivalent secure local format and appropriate fallback. |
| TYP-18, A11Y-01, A11Y-22 | Keep WCAG A/AA outcomes Diamond. Describe focus contrast against applicable criteria accurately; AAA focus geometry and an axe zero-violation result are not by themselves a WCAG conformance claim. Retain manual/process review. |

| RSP-02, RSP-03, RSP-08, RSP-10 | Keep WCAG reflow at 320 CSS px Diamond. The much wider screenshot matrix and physical-device sweep are Gold coverage; scope device evidence to the supported audience and journeys. |

| MAIL-01, MAIL-02, MAIL-03, MAIL-04 | Preserve existing senders and classify actual transactional versus marketing traffic. Apply legal/provider rules by audience and jurisdiction.
