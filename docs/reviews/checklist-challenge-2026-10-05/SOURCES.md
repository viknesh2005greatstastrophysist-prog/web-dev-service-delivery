# Sources and limits

Checked 2026-10-05. Sources support the technical distinctions; priority placement is the agency's risk judgment.

- [WCAG 2.2](https://www.w3.org/TR/WCAG22/): normative accessibility criteria, conformance levels and exceptions. AA and AAA are not interchangeable; a scanner score is not a conformance finding.
- [OWASP HTTP Headers Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/HTTP_Headers_Cheat_Sheet.html): header purpose and context; generic server identification is not the same as disclosure of a vulnerable version or a secret.
- [Web Vitals](https://web.dev/articles/vitals): lab and field evidence serve different purposes; thresholds are not identical to an arbitrary Lighthouse score or a reference site's timings.
- [ICO storage and access guidance](https://ico.org.uk/for-organisations/direct-marketing-and-privacy-and-electronic-communications/guidance-on-the-use-of-storage-and-access-technologies/): determine the actual technology, jurisdiction and applicable consent or exception conditions. Cookie banners are not universal proof of privacy compliance.
- [FTC advertising and marketing guidance](https://www.ftc.gov/business-guidance/advertising-marketing): claims need to be truthful and supportable.
- [Skills directory](https://skills.sh/): workflow discovery only, not evidence that a requirement is necessary or correct.

Reviewer source notes accompany the complete row decisions. Legal applicability still needs the actual business, audience, service, data flows and qualified review. This review does not certify any site's compliance.
