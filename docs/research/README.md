# Research

Notes behind the gold-standard pass of the checklist (2026-10-01). Each file lists the sources fetched and marks
pure judgment as (J).

- `verified-facts-gold-pass.md`: facts verified from primary pages before the rows were written (response-time
  limits, Lighthouse scoring curve, web.dev guidance, 404 and form-error guidance, tap targets).
- `gold-proposals-speed-errors-ux.md`: the proposed rows for speed, error pages and the experience section (UXF).
- `gold-proposals-other-sections.md`: the proposed rows for typography, responsive, accessibility, motion, SEO,
  internationalisation, security, email, hosting, operations, legal and delivery.
- `gold-benchmark-table.md`: the reviewer's table checking each gold target against the 2025 Web Almanac,
  Lighthouse's scoring code and external checklists, with a verdict for each.

The proposals are the first draft. The reviewed rows are in `checklist/`; where they differ, the checklist wins.
